# 5. Files

    <leader><space>   find a file by name
    <leader>fr        recent files
    <leader>fn        new empty file
    :e path           open a path
    :w  :wq  :q       save, save and quit, quit

The file explorer, `<leader>e`:

    j k          move
    l  enter     open a file, expand a folder
    h            collapse
    a  r  d      add, rename, delete
    c  m  p      copy, move, paste
    /            search the whole tree
    .            show hidden files

`ctrl-h` and `ctrl-l` move between the explorer and the editor.
