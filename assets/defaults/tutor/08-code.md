# 8. Code

A language server starts on its own once the project is trusted and
the server is installed.

    K            documentation
    gd  gr       definition, references
    gI  gy       implementation, type definition
    <leader>ca   code actions
    <leader>cf   format the file
    <leader>ss   symbols in this file
    ]d  [d       next / previous problem
    <leader>xx   every problem in a list

Completion pops up while you type; `enter` accepts, `ctrl-space` asks.
