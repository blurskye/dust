# Welcome

The card at the bottom right is your teacher. It gives you one thing to
try at a time, opens the lesson and moves on by itself once you've done
it.

    :TutorNext   skip a step
    :TutorBack   go back a step
    :TutorQuit   stop and put your own files back
    :Tutor       pick up where you left

This is a throwaway practice project: one short lesson file per chapter,
a small Rust program in `src/` and a git repository with one changed
file. Edit it, break it; it is deleted when the tutor ends.

`<leader>` is the space bar. Press it and wait, and a box lists what can
follow, so you never need to remember a whole key sequence.
