# 10. Debugging

    <leader>db   toggle a breakpoint      <leader>dB  conditional one
    <leader>ds   start debugging          <leader>dc  continue
    <leader>dO   step over                <leader>di  step into
    <leader>do   step out                 <leader>dt  stop
    <leader>dr   the debug console        <leader>dR  restart

While paused, the current line is marked and the debug panes show the
stack and variables.
