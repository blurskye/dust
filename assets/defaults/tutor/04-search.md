# 4. Search and replace

    /word     search forward          ?word   search backward
    n  N      next / previous match
    *  #      search the word under the cursor

Across the project:

    <leader>/    search every file
    <leader>sr   search and replace across files, with a preview
    <leader>st   TODO, FIXME and HACK comments

In any list: type to filter, `enter` opens, `esc` switches the list to
Normal mode, a second `esc` closes it.
