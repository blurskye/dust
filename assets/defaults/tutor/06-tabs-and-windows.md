# 6. Tabs and windows

Every open file is a tab at the top.

    ctrl-t        new tab with the file finder
    ctrl-q        close the tab
    H  L          previous / next tab
    <leader>,     pick an open buffer
    <leader>bp    pin the buffer

Windows split the screen:

    <leader>|     split side by side
    <leader>-     split top and bottom
    ctrl-h ctrl-j ctrl-k ctrl-l   move between windows
    ctrl-arrows   resize
    <leader>wm    zoom the window and back
    <leader>wd    close the window
