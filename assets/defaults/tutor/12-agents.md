# 12. Agents

Coding agents (Claude, Codex, OpenCode, pi, Gemini) run in a panel
beside your code.

    <leader>an   start an agent
    <leader>aa   ask, with the selection if there is one
    <leader>af   add this file to the next question

In the panel:

    enter        send                 shift-enter  new line
    esc          Normal mode          i            type again
    ctrl-t       new agent tab        H  L         switch tabs
    ctrl-p       model or agent       ctrl-o       mode and options
    ctrl-r       resume a conversation
    ctrl-h       back to the code
